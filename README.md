# WeChat Mini Game Industry Deep Research Prompt

用于对微信小游戏行业进行系统、可验证、面向决策的深度研究。

## 文件

- `wechat-mini-game-industry-deep-research-prompt.md`：完整母提示词，可直接用于 ChatGPT Deep Research、研究型 Agent 或其他联网研究模型。

## 设计目标

这份提示词不是让模型“整理行业新闻”，而是要求它建立：

问题 → 检索 → 证据 → 交叉验证 → 反证 → 判断 → 决策含义

默认覆盖：

- 行业规模与阶段
- 微信生态与平台政策
- 产品与玩法趋势
- 用户结构
- 买量与素材
- IAA / IAP / 混合变现
- 头部产品与发行商
- 技术与 AI 影响
- 未来 12–18 个月趋势
- 对产品立项、研发与发行的实际含义

## 使用方法

复制完整提示词，在 `<UserContext>` 中填写本次研究问题、团队背景或重点品类后执行。

如果不填写，提示词会按“中国大陆微信小游戏行业整体研究”的默认范围运行。

## 研究原则

1. 严格区分微信小游戏、抖音小游戏、App 手游和普通小程序。
2. 当前数据必须标注时间和口径。
3. 优先一手资料；关键结论至少交叉验证。
4. 不把素材量、投放量、榜单曝光和流水增长混为一谈。
5. 主动搜索反证、失败案例和相反解释。
6. 无法确认的数据明确标为未知，不用估算补齐。
