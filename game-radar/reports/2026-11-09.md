今日结论

今日共筛出4个正式候选，其中1个强推荐、3个观察。

强推荐是Worst Class Ever的“老师观察异常、学生伪装搞事”非对称派对核心。免费Demo支持1至6人，开发团队公布其在Steam新品节按玩家数排名第一、累计超过60万玩家，说明题材和多人关系已经获得显著试玩验证。原作依赖3D教室、走位、道具和多地图，不适合完整复制；但核心可以压成2D俯视或单屏课堂：五名学生在固定座位间完成吃零食、传纸条、玩手机等短任务，一名老师轮流扫描异常。建议只验证“伪装、观察、指认、误判”四步，不复制原作地图和道具规模。

PeeVPee的免费Demo已经具备在线PvP、在线合作、新增团队模式和全球排行榜，抢地盘、推人和反超都适合短视频。但排尿主题、成人内容标签、部分地区限制与3D空间依赖会直接影响平台合规、品牌接受度和投放范围，因此只建议借鉴“蓄力液体占地加抢点”的机制，不建议照搬题材。

Needle in a Haystack已在浏览器、移动浏览器及CrazyGames移动应用可玩，平台多人目录标注最多8人。它只有“翻找草堆、找到针、比时间”一条规则，围观和抢先发现天然成立；但原作以3D第一人称移动和镜头为主，日期信号是10月发布、11月2日更新，不是当天首发，因此列为观察。

Pidgeon Pocket计划于11月9日进入抢先体验，免费Demo已可玩，2D俯视、瞄准放飞、偷取和连锁反馈易于改造。它的问题是原生单人、长期增量和升级树较重，近期试玩评论也指出节奏慢、重复和经济挫败。只建议抽取“派出小队、避开抓捕、连续偷取”的60秒好友挑战，不复制完整养成。

Epic、Xbox、PlayStation、Nintendo、iOS与Android的当天公开发行信号主要为移植、成熟IP、重动作、经营或单人作品，没有出现比上述候选更同时满足低门槛、低成本2D化与自然社交的新项目。itch.io、Newgrounds、Poki、Game Jolt、gx.games与AI原生游戏平台或社区未检索到日期、玩法和可玩状态都足够完整、且高于正式候选的新项目，因此不为凑数列入。

1. Worst Class Ever

核心玩法一句话：一名老师观察整间教室，找出混在大量NPC学生中偷偷吃零食、传纸条和玩手机的五名真人学生；学生要伪装正常并趁老师转身完成恶作剧。
为何适合玩吧：身份关系一句话就能理解，老师和学生天然形成追捕、欺骗、围观、甩锅与复仇；学生做坏事和老师误抓都能在首秒建立冲突，适合固定好友房和陌生人快速组局。

上手门槛：约一局。学生只需理解“老师不看时搞事”，老师只需理解“观察异常并点名”；首版应把恶作剧压到三种，避免道具教学。
相对热门产品的新意：相对常见狼人杀，它不依赖长文本发言和投票，而是用可见行为露馅；相对捉迷藏，它把伪装对象放在固定课堂秩序中，学生必须一边装正常一边完成小任务。
预估改造成本：中。单地图、三种恶作剧、六人房间和基础NPC可做中等规模原型；若扩展多地图、道具、语音、反作弊和高并发匹配，成本会上升到中高。建议先做2D单屏，不做3D。
主要风险：完整版尚未在本次截点解锁；开发方公布的60万玩家属于Demo玩家数，不等于留存或付费；六人局需要匹配和断线补位；老师过强会让学生挫败，学生语音串通又可能破坏老师体验；校园恶作剧需控制危险道具与欺凌表达。
推荐等级：强推荐。推荐的是经过大规模Demo验证的“观察异常加伪装搞事”关系核心，不是原作的3D内容规模。

2. PeeVPee

来源平台：Steam，Windows与Linux；免费Demo
上线或测试日期：Demo商店页标注2026-10-17发布；完整版计划2026-11-09解锁，本次截点仍显示尚未发售

推荐等级：观察。仅借鉴“蓄力液体占地加团队抢点”，不建议沿用排尿与裸露题材。

3. Needle in a Haystack

来源平台：CrazyGames浏览器版，覆盖桌面、手机、平板及CrazyGames iOS与Android应用

上手门槛：几秒。看到草堆和针图标即可理解“找到并点中”。
相对热门产品的新意：相对静态找物，它让玩家主动翻动遮挡并与多人争夺唯一目标；相对普通竞速，它的冲突来自信息发现而不是操作精度。
预估改造成本：低到中。2D草堆、遮挡、随机针位置和异步榜成本低；多人实时翻动同一草堆、反作弊和观战提示会提升到中等。可先用同种子异步竞速规避同步成本。
主要风险：当前页面只给出月份与11月2日更新，不是当天新作；原作3D操作与低成本2D目标不一致；寻找过程可能长时间没有反馈；随机位置不公平会破坏竞技；针的体积过小会造成可访问性和视觉疲劳。
推荐等级：观察。适合做极轻2D好友竞速原型，但需要先证明重复可玩性。

平台扫描摘要

Steam：正式候选保留Worst Class Ever、PeeVPee与Pidgeon Pocket，并把Demo可玩、计划解锁和正式上线分开表述。Safari-TV、The Big Suck、Handshakes: Hands On、Cannon War、Tube2K与Mini Mart Survivors分别因3D高成本、复杂经济、日期不足、重策略或重战斗排除。
CrazyGames：Needle in a Haystack于10月发布、11月2日更新，可在桌面和移动端直接试玩；多人目录标注最多8人，作为近期观察进入正式候选。其他11月更新项目多为旧作维护或重3D动作，没有更好的低成本2D新品信号。
Epic、Xbox、PlayStation、Nintendo：Hozy主机版是11月9日较明确的新信号，但属于单人慢节奏清洁与装饰；其余公开日历主要为大作、移植、成熟IP或较重产品，没有新增正式候选。
iOS、Android：Needle in a Haystack可通过CrazyGames移动端和应用体验；本窗口未发现日期、玩法、社交和低成本2D证据均完整、且高于正式候选的原生移动新品。
itch.io：完成最新HTML5、多人、单键、反应、物理与派对组合检索，索引页没有同时给出准确发布日期与足够玩法证据的新项目，故不列入正式候选。
Newgrounds、Poki、Game Jolt、gx.games：检索到的可玩项目多为旧作、旧更新、重动作或日期证据不足；没有高于正式候选的新项目。
AI原生游戏平台与社区：未发现2026-11-09附近同时具备公开可玩入口、明确发布日期、低门槛社交机制和低成本2D改造证据的新项目。AI辅助开发仅作为供给和确权风险，不作为推荐加分。
去重结果：Worst Class Ever、PeeVPee、Needle in a Haystack、Pidgeon Pocket、Safari-TV、The Big Suck、Handshakes: Hands On、Hozy、Cannon War、Tube2K与Mini Mart Survivors在仓库历史日报全文检索中均无命中。

今日优先行动

第一优先：制作Worst Class Ever式2D单屏课堂原型。只保留观察异常、学生伪装、三种恶作剧和一次指认，用小规模真人房验证关系张力，不做多地图和道具体系。

第二优先：把PeeVPee机制去题材化，做2D泡沫占地2对2。重点验证蓄力、覆盖、反超和守点是否在没有低俗题材时仍然好玩。

第三优先：用两天级原型对比Needle in a Haystack的20秒好友找针和Pidgeon Pocket的60秒同图鸽群竞速。只有好友成绩显著提升再战与分享时才进入后续开发。

暂不投入：Safari-TV的3D多人经营与车辆物理、The Big Suck和Tube2K的长线增量经济、Cannon War的塔防构筑、Mini Mart Survivors的弹幕肉鸽。
